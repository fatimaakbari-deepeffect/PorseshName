# پرسش‌نامه پژوهشی — راهنمای راه‌اندازی کامل

پروژه‌ای کاملاً رایگان برای انتشار پرسش‌نامه روی GitHub Pages و ذخیره پاسخ‌ها در Google Sheets از طریق Google Apps Script.

## ساختار پروژه

```
.
├── index.html
├── style.css
├── script.js
├── questions.js          # تعریف سؤالات (قابل ویرایش)
├── config.js             # تنظیمات (آدرس Web App)
├── apps-script/
│   └── Code.gs           # کد Google Apps Script
└── README.md
```

---

## بخش ۱: آماده‌سازی Google Sheet و Apps Script (ابتدا این بخش)

### ۱. ساخت Google Sheet
1. به [sheets.google.com](https://sheets.google.com) بروید و یک Sheet جدید بسازید.
2. نام آن را مثلاً «پاسخ‌های پرسش‌نامه» بگذارید.
3. **Sheet را عمومی نکنید.** دسترسی فقط برای شما (Owner) باشد.
4. شناسه Sheet (در URL) را نگه دارید — نیازی به قرار دادن در کد نیست، Apps Script به Sheet فعال متصل می‌شود.

### ۲. ایجاد Google Apps Script
1. در همان Sheet: **Extensions → Apps Script**.
2. کد پیش‌فرض را پاک کنید.
3. محتوای فایل `apps-script/Code.gs` را کپی و جایگذاری کنید.
4. **Save** (Ctrl+S).

### ۳. تنظیم دسترسی‌ها و انتشار Web App
1. روی **Deploy → New deployment** کلیک کنید.
2. نوع: **Web app**.
3. توضیحات: «پرسش‌نامه».
4. **Execute as**: Me (حساب شما).
5. **Who has access**: Anyone (برای دسترسی عمومی فرم؛ داده‌ها در Sheet خصوصی می‌مانند).
6. **Deploy** → مجوزها را تأیید کنید.
7. **Web app URL** را کپی کنید (فرمت: `https://script.google.com/macros/s/XXXX/exec`).

### ۴. اتصال فرانت‌اند به Web App
1. فایل `config.js` را باز کنید.
2. مقدار `WEB_APP_URL` را با URL دریافتی جایگزین کنید:
   ```js
   WEB_APP_URL: "https://script.google.com/macros/s/XXXX/exec"
   ```
3. ذخیره کنید.

### ۵. آزمایش ثبت پاسخ
1. فایل `index.html` را در مرورگر باز کنید (یا با یک سرور محلی).
2. پرسش‌نامه را تکمیل و ثبت کنید.
3. Google Sheet را بررسی کنید: باید یک ردیف جدید با ResponseID و Timestamp اضافه شده باشد.

### ۶. مشاهده پاسخ‌ها در Google Sheets
- هر پاسخ‌دهنده یک ردیف مستقل دارد.
- ستون‌ها: ResponseID, Timestamp, و یک ستون برای هر سؤال (به نام id سؤال).
- پاسخ‌های چندانتخابی با `;` جدا شده‌اند.
- برای خروجی Excel/CSV: **File → Download → CSV / Excel**.

## بخش ۲: انتشار روی GitHub Pages

### ۷. ایجاد Repository
1. در GitHub یک Repository جدید بسازید (مثلاً `psych-survey`).
2. فایل‌های پروژه را آپلود کنید (index.html, style.css, script.js, questions.js, config.js, README.md).
   - **هیچ اطلاعات حساسی (رمز، توکن) را commit نکنید.** `config.js` فقط URL عمومی Web App را دارد که مشکلی ندارد.
3. در Settings → Pages: Source = main branch / root.
4. آدرس سایت: `https://<username>.github.io/psych-survey/`

### ۸. تست نهایی
- لینک را روی موبایل و دسکتاپ باز کنید.
- تمام انواع سؤالات را تست کنید.
- اعتبارسنجی سؤالات اجباری را بررسی کنید.
- ثبت چندباره ناخواسته را تست کنید (localStorage).
- ثبت پاسخ در Sheet را تأیید کنید.

## امنیت و محدودیت‌ها

- **GitHub Pages** فقط فایل‌های فرانت‌اند را میزبانی می‌کند؛ هیچ بک‌اندی وجود ندارد.
- **Google Apps Script** نقش پردازش و دریافت اطلاعات را دارد و به‌صورت Web App منتشر می‌شود (دسترسی «Anyone»).
- Sheet **عمومی منتشر نمی‌شود**؛ فقط Owner به آن دسترسی دارد.
- اعتبارسنجی سمت سرور: بررسی وجود responseId و answers، جلوگیری از ثبت تکراری (responseId)، LockService برای همزمانی.
- **محدودیت‌ها**: Apps Script سهمیه روزانه دارد (۲۰٬۰۰۰ درخواست/روز برای حساب رایگان) — برای ۱۰–۱۵ پاسخ کاملاً کافی است. CORS: به دلیل محدودیت‌های Apps Script، درخواست با mode `no-cors` ارسال می‌شود و پاسخ خوانده نمی‌شود؛ موفقیت بر اساس عدم خطای شبکه تعیین می‌شود.
- هیچ اطلاعات حساس مدیریتی در کدهای عمومی GitHub قرار ندارد.

## تغییر سؤالات و گزینه‌ها در آینده

1. فایل `questions.js` را باز کنید.
2. برای سؤال جدید: یک شیء به `QUESTIONS` اضافه کنید (id یکتا)، و id را به `SECTIONS[...].questionIds` اضافه کنید.
3. برای سؤال شرطی: `condition: (a) => a.q_xxx === "..."` تنظیم کنید.
4. برای گزینه «سایر»: `hasOther: true`.
5. ستون متناظر در Google Sheet به‌صورت **خودکار** در اولین ثبت جدید ایجاد می‌شود.
6. تغییرات را commit/push کنید تا GitHub Pages به‌روز شود.

## فرضیه‌های پژوهش (نمایش در پایان پرسش‌نامه)

1. بین همذات‌پنداری با محتوای روان‌شناختی شبکه‌های اجتماعی و خودبرچسب‌زنی روان‌شناختی رابطه مثبت وجود دارد.
2. بین تفکر نقادانه و خودبرچسب‌زنی روان‌شناختی رابطه منفی وجود دارد.
3. تفکر نقادانه رابطه بین همذات‌پنداری با محتوای روان‌شناختی و خودبرچسب‌زنی روان‌شناختی را تعدیل می‌کند؛ به‌گونه‌ای که با افزایش تفکر نقادانه، شدت رابطه مثبت بین همذات‌پنداری و خودبرچسب‌زنی کاهش می‌یابد.
